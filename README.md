# 🇰🇷 Kore'den Kaçış

Güney Kore'de doğup büyüdüğün, ailenle, okulla, askerlerle ve sistemle mücadele ettiğin; sonunda ülkeden kaçmaya çalıştığın **hikaye tabanlı 2D tarayıcı oyunu**.

Saf HTML5 Canvas + JavaScript ile yazıldı. Kurulum gerekmez, tarayıcıda çalışır, GitHub Pages'te yayınlanabilir.

---

## 🎮 Oynanış

- **WASD** — Hareket (W ileri, A sol, S geri, D sağ)
- **Shift** — Hızla koş (enerji harcar)
- **C** — Çömel (askerlere görünmezlik, saklanma)
- **Boşluk / Enter** — Diyalog ilerlet, etkileşim
- **I** — Envanter aç
- **K** — Yetenek ağacı aç

### 2 Kişilik Yerel Mod
- **P1:** WASD + Shift + C
- **P2:** Ok tuşları + Sağ Shift + Sağ Ctrl

### Mobil
Ayarlar → Mobil Kontroller aç. Ekranda joystick + KOŞ / ÇÖM / KULLAN butonları çıkar.

## 📖 Hikaye

6 bölüm:

1. **Çocukluk** — Seul'de bir aile. Anne, baba, baskı.
2. **Okul Baskını** — Askerler okulu basar. Baban boyun eğer, sen eğmezsin.
3. **Dershane (Hagwon)** — Suneung sınavı. Ailenin tüm umudu sende.
4. **İş Hayatı** — Patron, mesai, para. Kaçmak için birikim.
5. **Arkadaş** — Biri daha kaçmak istiyor. Yanına alır mısın?
6. **Kaçış** — Sınır. Askerler. 3 farklı rota. Geri sayım.

**7 farklı son:** Rüşvet, koşarak kaçış, yakalanma, teslim, arkadaşla kaçış, aile iknası, tükenme.

## ✨ Özellikler

### Çekirdek
- 6 bölümlük hikaye, diyaloglar, seçimler
- 3 zorluk seviyesi (Kolay / Normal / Zor)
- 2 kişilik yerel mod
- Karakter oluşturma (cinsiyet, saç, ten, kıyafet, atmosfer)
- Kullanıcı adı + karakter adı (skor tablosunda görünür)

### Mekanikler
- **Para sistemi** — İş mini oyunuyla kazan, yetenek satın al, rüşvet ver
- **Enerji** — Koşunca azalır, dinlenince dolar
- **Görünürlük barı** — Askerler yaklaşınca artar, çömelince azalır
- **İlişki puanları** — Anne, baba, arkadaş (seçimler değiştirir)
- **Yetenek ağacı** — Hız, gizlilik, dayanıklılık, sağlık, karizma
- **Envanter** — Sahte kimlik, harita, bilet, telefon, arkadaş
- **Yakalanma sayacı** — 3 kez yakalanırsan oyun biter
- **Telefon aramaları** — Anne arar, cevapla/yoksay
- **Gizli aile sırrı** — Babanın geçmişi

### Kaçış
- **3 rota:** Dağ (kolay-uzun), Liman (orta), Tren (zor-kısa)
- **Geri sayım** — Süre dolarsa yakalanırsın
- **Flashback'ler** — Kaçarken çocukluk anıları
- **7 farklı son**

### Sistem
- **Kaydet / yükle** — Otomatik (30 sn'de bir), "Devam Et" butonu
- **15 başarım** — Bildirim toast'ı ile
- **Profil kartı** — Menüde isim + kaçış sayısı + rekor para
- **Skor tablosu** — LocalStorage'da 15 skor
- **Paylaşım** — Sonucu panoya kopyala
- **Dil** — Türkçe / English
- **Renk körü modu** — Askerler mavi, uyarılar turuncu
- **Ekran sarsıntısı kapatma**
- **Mobil dokunmatik kontrol**

### Görsel
- Stilize 2D karakter (kafa, gövde, kol, bacak, animasyon)
- Gece neon tabelalar (Korece yazılar)
- Yağmur, kar, gün/gece döngüsü
- Parçacık efektleri (hasar, hareket)
- Dinamik ışık kaynakları
- Portre sistemi (diyalogda yüz)
- Mini harita
